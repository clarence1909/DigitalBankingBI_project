# Kelip Bank: Digital Banking BI

An end-to-end business intelligence project for Kelip Bank, a fictional Malaysian digital bank. It takes six simulated source systems through a SQL warehouse to a KPI scorecard, a Tableau dashboard and an Excel KPI pack, all rebuilt with one command.

> **All data is synthetic.** Kelip Bank does not exist. Every customer, account and transaction is generated by a seeded Python simulator; nothing comes from a real bank or real customers.

**Status:** In progress. The project set-up is done, and each part below is being added in turn.

## What the project covers

- **Bank:** Kelip Bank, a fictional Malaysian digital bank, with 24 months of data (September 2024 to August 2026)
- **Products:** savings accounts (CASA), fixed deposits, a debit card and personal financing
- **Audiences:** the executive committee, growth and onboarding, treasury, cards, credit risk and finance
- **Sources:** six systems in four formats (CSV, JSON, Parquet and Excel): app events, customers and accounts, ledger postings, card authorisations, loans, and a hand-kept marketing spreadsheet
- **Tools:** Python, DuckDB (SQL), Tableau Public, Excel (built with openpyxl) and GitHub Actions, all free

## How to run it

You need Python 3.11 or newer and Git.

1. Clone the repository:

```bash
   git clone https://github.com/clarence1909/DigitalBankingBI_project.git
   cd DigitalBankingBI_project
```

2. Create and activate a virtual environment:

```bash
   python3 -m venv .venv          # Windows: python -m venv .venv
   source .venv/bin/activate      # Windows: .venv\Scripts\activate
```

3. Install the pinned packages:

```bash
   pip install -r requirements.txt
```

4. Rebuild everything:

```bash
   python run_pipeline.py
```

## Project structure

| Path | What goes in it |
|---|---|
| `run_pipeline.py` | One command: generate, load, model, check, publish |
| `requirements.txt` | Pinned Python packages |
| `data/raw/` | Generated source files (not in Git) |
| `data/sample/` | A small sample of each source, to show the formats |
| `data/reference/` | KPI catalog, plan targets and lookup tables |
| `data/warehouse/` | DuckDB warehouse file (not in Git) |
| `sql/01_staging/` | Clean, type and de-duplicate each source |
| `sql/02_marts/` | Star schema: dimensions and facts |
| `sql/03_kpi/` | KPI tables and the scorecard |
| `sql/tests/` | Data quality checks and reconciliations |
| `sql/adhoc/` | Example stakeholder questions |
| `src/` | Generator, loader, checks, analysis and exports |
| `dashboards/` | Tableau build notes and extracts |
| `reports/` | Insights report, charts and the Excel KPI pack |
| `docs/` | Requirements, design, dictionaries, user manual and decision log |
| `.github/workflows/` | CI: runs the pipeline and checks on every push |
